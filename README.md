# Liminal

**Liminal** is an open-source audio synthesiser available as a VST3, AU, and AUv3 plugin, and as a standalone application for macOS, Windows, and iPad.

Current state: In progress.

---

## Formats

| Format | Platform |
|---|---|
| VST3 | Windows, macOS |
| AU | macOS |
| Standalone | Windows, macOS |
| AUv3 | iPad |

## Contributing

Contributions are welcome. By submitting a pull request you agree that your contribution will be licenced under the GPLv3, consistent with the rest of the project.

**Guidelines:**
- Open an issue before starting significant work — this avoids duplicated effort
- Keep pull requests focused; one feature or fix per PR
- Follow the existing code style
- Test across at least one DAW on macOS or Windows before submitting

Bug reports, feature requests, and general feedback are all appreciated via [GitHub Issues](../../issues).
